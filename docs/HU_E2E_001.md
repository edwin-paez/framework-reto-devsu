# Historia de Usuario

Como **Ingeniero QA Automation**,

quiero automatizar el flujo principal de compra de SauceDemo,

para validar de forma repetible que un usuario autenticado puede completar una compra exitosamente y garantizar la consistencia de la información presentada durante todo el proceso.

---

# Objetivo

Implementar una prueba E2E utilizando Serenity BDD y Screenplay que valide el flujo completo de compra, verificando tanto el comportamiento funcional como la integridad de los datos mostrados al usuario durante el proceso.

---

# Alcance

La automatización deberá cubrir:

1. Autenticación del usuario.
2. Selección de dos productos.
3. Validación del contenido del carrito.
4. Inicio del Checkout.
5. Registro de la información del comprador.
6. Validación del resumen de compra.
7. Confirmación de la orden.

---

# Fuera de Alcance

- Casos negativos.
- Validaciones visuales.
- Compatibilidad Cross Browser.
- Pruebas de rendimiento.
- Pruebas de seguridad.

---

# Reglas de Negocio

### RN-001

El usuario debe autenticarse con credenciales válidas.

### RN-002

El usuario debe agregar exactamente dos productos al carrito.

### RN-003

Durante la selección de productos deberán capturarse:

- Nombre
- Precio

Esta información será utilizada para validar la consistencia de la compra en los pasos posteriores.

### RN-004

El carrito deberá contener exactamente los productos previamente seleccionados.

### RN-005

Para completar el Checkout el usuario deberá ingresar:

- First Name
- Last Name
- Postal Code

### RN-006

Antes de confirmar la orden deberá validarse que:

- Los productos coinciden con los seleccionados inicialmente.
- Los precios individuales son correctos.
- El subtotal corresponde a la suma de los productos.
- El impuesto mostrado es consistente.
- El total corresponde a:

```
Subtotal + Tax = Total
```

### RN-007

La compra será considerada exitosa únicamente cuando el sistema presente el mensaje:

> THANK YOU FOR YOUR ORDER

# Comportamiento esperado por cada paso

## Given un usuario autenticado

Debe permitir el acceso exitoso al inventario de productos.

---

## When agrega dos productos al carrito

La automatización deberá:

- Seleccionar dos productos disponibles.
- Capturar el nombre de cada producto.
- Capturar el precio de cada producto.
- Conservar esta información durante toda la ejecución para realizar validaciones posteriores.

---

## And inicia el proceso de checkout

La automatización deberá validar que:

- Los productos del carrito corresponden exactamente a los seleccionados.
- Los nombres coinciden.
- Los precios coinciden.
- La cantidad de productos es correcta.

---

## And completa la compra

La automatización deberá:

- Registrar la información del comprador.
- Acceder al resumen de la orden.
- Validar nuevamente los productos seleccionados.
- Validar el subtotal.
- Validar el impuesto mostrado.
- Calcular el total esperado.
- Comparar el total calculado con el total mostrado por la aplicación.
- Confirmar la orden.

---

## Then el sistema muestra el mensaje de confirmación de compra

La automatización deberá verificar:

- El mensaje de compra exitosa.
- Que la compra finalizó correctamente.
